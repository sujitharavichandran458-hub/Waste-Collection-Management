\# EcoTrack – Waste Collection Management and Environmental Data Analysis System



\## Scenario 23



\## 1. Project Overview

EcoTrack is a web-based Waste Collection Management and Environmental Data Analysis System developed to manage waste collection activities and analyze waste data efficiently.



The system helps administrators manage collection areas, vehicles, waste collection records and reports.

\## 4. Database

Database: PostgreSQL



Database Name: waste\_management1



The database stores area, vehicle and waste collection information.



\## 5. How to Run the Application



1\. Install Java and PostgreSQL.

2\. Create the PostgreSQL database named `waste\_management1`.

3\. Configure database credentials in `application.properties`.

4\. Open the `waste-collection-management` project folder in VS Code.

5\. Open the terminal.

6\. Run:



&#x20;  `mvn spring-boot:run`



7\. Open the browser and visit:



&#x20;  `http://localhost:8080`
